# java-lotto-precourse

## 💎 프로젝트 소개
**LOTTO**는 사용자가 입력한 금액만큼 로또를 구매하고,
당첨 번호와 비교하여 **당첨 여부 및 수익률**을 출력하는 프로그렘입니다.

---

## 🎯 기능 요구 사항
- 로또 번호의 숫자 범위는 **1~45**이다.
- 1개의 로또를 발행할 때 **중복되지 않는 6개의 숫자**를 뽑는다.
- 당첨 번호 추첨시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- **로또 구입 금액을 입력**하면 구입 금액에 해당하는 만큼 로또를 발생해야 한다.
- 로또 1장의 가격 : **1000원**
- 당첨 번호화 보너스 번호를 입력받는다.
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료
- 잘못된값이 입력되면 예외처리

---

### 💰 당첨 금액 및 조건
- 당첨 금액은 1등부터 5등까지
   - 1등: 번호 6개 일치 / 20억원
   - 2등: 번호 5개 + 보너스 번호 일치 / 3천만원
   - 3등: 번호 5개 일치 / 150만원
   - 4등: 번호 4개 일치 / 5만원
   - 5등: 번호 3개 일치 / 5천원

---

### 🔧 예외 처리
- 중복된 번호가 입력된 경우
- 보너스 번호와 당첨 번호와 중복되는 경우
- 구입금액이 1000원 단위가 아닌 경우
- 로또 번호가 1 ~ 45 범위를 벗어난 경우
